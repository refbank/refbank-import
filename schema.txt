
For import should make the following as one dataframe, then pass to the validate_dataset() function which will do some checks.

These are all the columns for the dataframe. Here we're grouping based on what level it should vary with, but they all go in one dataframe.

(dataset-level):
  - dataset_id: character,  canonically lastnameyear_firstwordtitle where title is done to have at least one content word
  - full_cite: character, the APA format citation for the source paper
  - short_cite: character, the in-text citation, ex: Boyce et al. (2024)

(condition-level)
  - condition_label: character, a human-understandable name for the condition
  - group_size: numeric, how many people per group
  - language: character, the language used such as "English"
  - prior_relationship: character, "yes", "no", or "mixed" (for a condition whose participants are a known blend of acquainted and unacquainted pairs that can't be split further), whether participants knew each other before the study
  - partner_constancy: character, "yes" or "no", whether the partners stay the same for the whole game
  - population: character, "adult", "child", or "child-parent"; could add new values if we get other special populations
  - role_constancy: character, "yes" or "no", whether someone has the same [describer/matcher] role the whole time
  - confederates: character, "yes" or "no", whether confederates were used
  - modality: character, "written", "oral-remote", or "oral-in-person"
  - feedback: character, "full", "limited", or "none"
  - backchannel: character, "full", "limited", or "none"

(trial-level)
  - game_id:
  - room_num:
  - stage_num:
  - image_options: the set of choices, collapsed into a semicolon separated list, using str_c(choices, collapse=";")
  - target_image: which the correct target is, should be in image_options
  - trial_num: numeric, starting at 1, continuing to increase over entire experiment
  - round_num: numeric, repetition number starting at 1 (often block)
  - exclude: logical, was this trial excluded in the source
  - exclusion_reason: character, description of which exclusion criteria caused the exclusion
  - order_match: character, "order" or "match", whether the experimental task was about rearranging the order of images (so you could do different orders), or match where each trial has a specific target (can't move forward and back)
  - option_set_size: numeric, derived at merge time as the number of items in image_options (not produced by individual import scripts)

(action-level)
  - action_type: character, allowed values are (message, selection)
  - player_id: who did the thing
  - role: character, allowed values are (describer, matcher)
  - time_stamp: numeric, time in seconds into the trial when this action took place (even for timed-out, set to max/trial)

(player-level; constant per player_id)
  - age: numeric, participant age, or NA
  - gender: character, or NA -- current values are "male", "female", "nonbinary", and "unknown"
  - native_language: character, or NA
  - race: character, or NA -- currently free text, not yet standardized
  - education: character, "less-than-high-school", "high-school", "some-college", "bachelors", or "advanced-degree", or NA

(message-level; these are NA for selections)
  - text: character, use a spellchecked version if available, but do not apply any exclusions
  - message_num: numeric, the position within messages within trial, starting with 1 for the 1st message etc
  - message_irrelevant: logical, true if this is a message consisting only of chit-chat / non-task-relevant

(selection-level; these are NA for messages)
  - selected_image: what target was selected, values can be the values in image_options, "timed_out" (no selection made), or "unk" (an incorrect selection was made, but which specific image is unrecoverable from the source data)


Images are handled separately by import_images.R (not by individual import scripts). The values used in image_options and target_image must match image_id values in the images table. import_images.R derives the image metadata from the trial data by matching dataset_id and target_image values.

(images table; one row per unique image, written to image_data/image_metadata.csv)
  - image_id: the image identifier, matches target_image/image_options values in trials
  - image_type: character, "tangram", "fribble", "line drawing", or "photograph" (other options could be added)
  - kilogram_id: character, the identifier in the kilogram tangram set (e.g. "page-A", "page1-148"), or NA if not in kilogram
  - image_path: character, filename of the image file (e.g. "page-A.svg", "target.png"), or NA if no file
